# Unpluged-Al

Materjalid õpetajate ja tehisintellekti teemale — eriti **KOV tasandi** otsuste ja toe jaoks.

Riik viib ellu TI-hüppe; õpetajate igapäevane olukord sõltub paljuski **kohalikust omavalitsusest** (munitsipaalkoolid, aeg, tugi, töökorraldus).

## Peegel

- Tartu Ülikooli ajakiri [Peegel](https://peegel.ut.ee/index.php/node/1003) dokumenteeris õpetajate häda TI kasutamisel.
- **Peegli metoodika** = aus peegeldamine enne suuri muudatusi; raamat töötab nagu peegel — näitab, mida organisatsioon tegelikult vajab.
