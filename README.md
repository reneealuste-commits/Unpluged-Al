# Unpluged-Al

Resources for calm, focused self-care.

## EMDR Home Guide

A practical handbook for using gentle bilateral stimulation techniques at home.

**Open the guide:** [emdr-home-guide.html](emdr-home-guide.html)

The guide includes:

- Plain-language explanation of EMDR
- Step-by-step home protocol
- Real-world examples (anxiety, sleep, grief, work stress)
- Grounding techniques and safety guidelines
- Human-centered centered text layout for comfortable reading

> **Note:** This is a self-care resource, not a substitute for professional trauma therapy. See the guide for when to seek a licensed EMDR therapist.
