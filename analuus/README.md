## Metoodika

- **Ranger Handbook IPB:** Composition → Disposition → Strength → Recent Activities → Capabilities → COA
- **PMESII-PT:** poliitiline, majanduslik, sotsiaalne, info, taristu, füüsiline keskkond, aeg
- **ASCOPE:** alad, struktuurid, võimekused, organisatsioonid, inimesed, sündmused
- **NVC + trauma-teadlikkus:** me ei süüdistame — me küsimme *miks?* ja *mis vajadus?*
- **KPI / OKR:** mõõdetavad tulemused, mitte poliitilised lubadused
