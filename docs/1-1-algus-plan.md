# 1-1 algus: kaugemalt pihta

Strateegia: **üks omavalitsus, üks inimene, üks kohtumine** — mitte masskiri ega volikogu enne esimest 1-1.

„Kaugemalt“ = Harjumaal Tallinnast / keskusest eemale, kus on vähem isiklikku võrgustikku ja esimene 1-1 ei puudutab kohe „oma inimesi“.

---

## Miks 1-1 ja miks kaugemalt?

| 1-1 | Kaugemalt |
|-----|-----------|
| Aus tagasiside ilma volikogu surve | Vähem sotsiaalset riski („mida nad mõtlevad“) |
| Saad kuulata enne, kui jagad raamatut | Saad kogemuse enne koduvalda / tuttavate KOV-i |
| Lihtsam leida 30 min kalendrist | Kaugemad vallad on tihti tänulikud välise huvi eest |
| Esimene protokoll tuleb **pärast** 1-1, mitte enne | Videokõne = loomulik „kaugelt pihta hakata“ |

---

## 4-nädalane 1-1 rada

### Nädal 1 — üks e-kiri, üks inimene

- [ ] Saada **ainult Kuusalu** e-kiri (mall allpool)
- [ ] 3 konkreetset kuupäevi videokõneks (30 min)
- [ ] Kui vastus tuleb: kinnita 1-1, saada lühiteave PDF enne kõnet

### Nädal 2 — järel + järgmine

- [ ] Kuusalu: järelkiri, kui pole vastust (5 tööpäeva)
- [ ] Saada **Loksa** e-kiri (sama struktuur, teine nimi)
- [ ] Esimene 1-1 toimub (Kuusalu või Loksa)

### Nädal 3 — laiendus

- [ ] 1-1 järel: lühike kokkuvõte (3 punkti) oma märkmikku — see on tulevase volikogu alus
- [ ] Saada **Anija** e-kiri
- [ ] Teine 1-1

### Nädal 4 — kordamine

- [ ] **Lääne-Harju** e-kiri
- [ ] Üks 1-1 järel: küsi otse: „Kas see teema sobib teie hariduskomisjoni või volikogu istungile?“
- [ ] Esimene „kaugelt“ edulugu → kasuta järgmises kirjas: „Rääkisin juba [vald] haridusspetsialistiga…“

---

## 1-1 kohtumise struktuur (30 min, videokõne)

| Min | Tegevus |
|-----|---------|
| 0–5 | „Kuulame enne“ — kuidas TI-hüpe on nende koolidesse jõudnud? Mis on õpetajate top 2 mure? |
| 5–15 | Peegli 3 küsimust (paber või suuliselt) — vt `peegli-metoodika.md` |
| 15–22 | Lühiteave + raamatu idee (mitte pikk müük) |
| 22–28 | „Kas järgmine samm on hariduskomisjon?“ — üks konkreetne tegevus |
| 28–30 | Kokkuvõte: kes teeb mis, millal järelkõne |

**Reegel:** esimesel 1-1 **ära nõua** volikogu aega. Küsi luba: „Kas pärast seda kõnet saaks teema teie laua taha?“

## Kaugelt pihta — tehniline

- Esimene kontakt alati **e-kiri + videokõne** (Zoom / Teams / Google Meet)
- Füüsiline külastus **alles pärast** 1-1 või kui nad ise kutsuvad
- Raamat: pärast 1-1, kui nad ütlevad „jah, tooge“ — või saada PDF / link enne kõnet
