# 👂 ÕLESSANDED ALLÜKSUSTELE
## Uus kiht: Malevapealikud kui maastiku juhid

> *"Sõdurioskuste kursus ei jää barakist. See liigub alla poole tsiviilühiskonda — ja malevapealik on see, kes kuulab, koordineerib ja viib ellu."*

---

## 1. Mis see kiht on?

**Õlessanded allüksustele** tähendab:

```
RIIK (strateegia, seadus, ERMA)
         │
    MALEV (15 malevat Eestis)
         │
   MALEVAPEALIK ←——— "õlad" kuulavad maastikku
         │
   ┌─────┼─────┐
   │     │     │
malevkond  malevkond  Naiskodukaitse / Noored Kotkad
   │     │
   ÕLE   ÕLE  ← allüksuse "kuulmised" kohalikul maastikul
   │     │
 TSIVIIL TSIVIIL
 farmer  KOV
 puukool tarbija
 kogukond kool
```

**Õlg** = allüksus, kes **kuuleb** ja **raporteerib**, mis maastikul toimub.  
**Malevapealik** = juht, kes **koordineerib**, mida tsiviilid teevad ja **kuidas see mõjutab kohalikke elanikke**.

See ei ole sõjaväeline okupatsioon. See on **juhtimiskiht**, mis juba eksisteerib seaduses — me anname sellele **selge tsiviil-maastiku rolli**.

## 2. Malevapealik — juht, mitte poliitik

### Seaduslik alus (Kaitseliidu kodukord §21)

Malevapealik juba today:
- juhib maleva tegevust ja esindab malevat
- korraldab väljaõpet ja koolitust
- korraldab koostööd asutuste ja isikutega
- käsutab eelarvevahendeid

|------|-----------|------------------------|
| Malevapealik | Sõjaline maleva juht | **Regionaalne koordinaator** tsiviil + kaitse |
| Malevkonna pealik | Kompanii juht | **Kohalik kuulaja** — mis toimub vallas/linnas |
| Sõdurioskuste kursus | KL liikme baas | **Juhtimisoskuste export** ühiskonda |
| KOV | Omavalitsus | **Partner**, mitte ülemus |
| Tsiviil maastikul | Eraldi | **Allüksuse õla ulatuses** |

## 3. Mida malevapealik koordineerib maastikul?

### Konkreetsed tsiviiltegevused

| Tegevus | Kes teeb | Malevapealiku roll |
|---------|----------|-------------------|
| Puukooli loomine | Farmer + LEADER | **Koordineerib** — ühendab KOV + farmer + ERMA |
| Tarbijaliikumine "Osta Eesti" | Kodanikud | **Kuulab** nõudlust — raporteerib üles |
| Kriisitoidu varud | Tactical Foodpack / kodanik | **Kriisiplaan** — 2 nädala reegel |
| Kooli aiaprogramm | KOV + kool | **Malevkond** aitab kooli aiaga |
| Urban farm | Kogukond | **Naiskodukaitse + Noored Kotkad** kaasatud |
| Reguleeritud turu nõudlus | Tarbijad | **Anonüümne statistika** — kui palju, kus |
| ERMA growshop | Riigiettevõte | **Kohalik teenindus** — mitte poliitika |

### Kuidas mõjutab kohalikke elanikke?

Malevapealik vastutab, et tsiviiltegevus:

| Positiivne mõju | Kuidas tagada |
|-----------------|---------------|
| Töökohad maal | Puukoolid + ERMA võrgustik maleva piires |
| Turvalisus | Reguleeritud turg vähendab musta turgu |
| Kriisivalmidus | 2 nädala toiduvaru kodudes |
| Noored näevad tulevikku | Kotkad + Kodutütarde + kutsekool |
| Loodus lähemal | Kooli aiad, rohekoridorid |
| Aus raha | Raha jääb maleva piirkonda, mitte välja |

**Negatiivset mõju blokeeritakse:** must turg, välismaa growshopid, bürokraatia ilma tulemuseta.

## 4. Sõdurioskuste kursus → juhtimine ühiskonda

### Mis on juba olemas (Kaitseliidu kool)

| Kursus | Mida annab | Kuhu liigub ühiskonda |
|--------|------------|----------------------|
| **Aluskursus / sõdurioskused** | Distsipliin, meeskond, ülesanne | Iga KL liige on juht kodukohas |
| **Juhtimine praktikas 1 (JUP1)** | Juhtimise üldpädevus | Malevkonna pealikud, meeskonnajuht |
| **Juhtimine praktikas 2 (JUP2)** | Probleemi lahendamine | KOV kriisikomisjonid (Järvamaa eeskuju) |
| **Juhtimine praktikas 3 (JUP3)** | Ülesandekeskne juhtimine | Malevapealikud, allüksuste juhid |
| **Inimvara arendamine** | Väärtused, kultuur, instruktor | Koolid, kogukonnad, noored |
| **CIMIC / kriisikoolitus** | Tsiviil-sõjaline koostöö | Omavalitsused + partnerid |

### Juba toimiv eeskuju: Järvamaa 2024

> *"Korraga olid ühes ruumis kõikide Järvamaa omavalitsuste juhid, kriisikomisjonid ja partnerorganisatsioonid."*  
> — major Agur Kibur, Järva malevapealik

**See on täpselt Õlessanded mudel:** malevapealik + malevkonna pealik + KOV + tsiviilpartnerid **ühes ruumis**.

### Uus pipeline: kursus → maastik

```
SÕDURIOSKUSTE KURSUS (KL aluskursus)
         │
         ▼
JUP 1 → meeskonnajuht kogukonnas
         │
         ▼
JUP 2 → probleemide lahendaja (KOV, ERMA, puukool)
         │
         ▼
JUP 3 → malevkonna / maleva juht
         │
         ▼
MALEVAPEALIK → maastiku koordinaator
         │
         ▼
TSIVIILÜHISKOND saab juhtimisoskused "tasuta"
```

**Põhimõte:** Iga inimene, kes läbib sõdurioskuste kursuse, toob **juhtimisoskuse** oma kogukonda — ilma et riik maksaks eraldi koolituse eest.
