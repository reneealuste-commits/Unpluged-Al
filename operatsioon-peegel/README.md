# Operatsioon „Peegel" — interaktiivne teekond

Mänguline, mobiilisõbralik veebirakendus OPORD-i „Operatsioon Peegel" (paranemis-teekond) põhjal.
Puhas HTML/CSS/JS, progress salvestub `localStorage`-isse. Sisu: `data.js` (võetud OPORD Google Docist).

Ava `index.html` või deploy kaust staatilise saidina.
