## 2. Paljajalu kohandamine linnaruumis — võimalused

### A. Muruväljakud (Eesti kontekst — Lisa Z, Lisa AA)

| Element | Kirjeldus |
|---------|-----------|
| **Muru väljak** igas linnaosas | Mitte ainult üks suur park kesklinnas — **5 min jalgsi** igast elamupiirkonnast |
| Pind | Murukate, võimalusel **mitme tekstuuri** ala (muru + liiv + puit) |
| Koolid ja lastaiad | **Paljajalu alad** õuealal — liivakast, muru, puitlattid |
| Pühali mudel | Loodus **lähedal** — mitte ainult ekraan |

### B. Rahvusvaheline mudel — Korea „barefoot paths"

Lõuna-Korea linnad (nt **Uijeongbu**, **Hanam**) on süstemaatiliselt ehitanud **paljajalu teid** tühjaks jäänud linnaruumidesse — jõekaldad, pargid, kortermaja kõrval olev tühi maa.

| Komponent | Praktika |
|-----------|----------|
| **Materjalid** | Punane savi (hwangto), liiv, liivakivi, liiv — **mitte asfalt** |
| **Kuiv tee** | 50–200 m teed, mis ei muutu poriseks vihmaga (drenaaž, ~20 cm tihendatud kiht) |
| **Jalavann** | Väike 20 m² ala — jalgu pesta enne ja pärast |
| **Jalatsiriiul** | Kingad maha — teadlik rutiin |
| **Juhend** | Omavalitsuse **loomise ja hoolduse käsiraamat** (standard, mitte juhuslik muruplats) |
| **Kogukond** | „Paljajalu teede hoidjad" — vabatahtlikud + hooldus |

**Mida Eesti omavalitsus saab üle võtta:**
1. Vali **väike ala** kortermaja, kooli või jõekalda kõrval
2. Ehita **kuiv paljajalu tee** (liiv + kergkate) või muruplats
3. Lisa **jalapesu** ja riiul
4. Märgi kaardil — inimesed peavad teadma, et see **on olemas**

### C. Pehmed jalakäijate teed

| Variant | Kasutus |
|---------|---------|
| Murukattega kõnnitee | Pargis, kooli ümbruses |
| Puitlattid / kergkate | Märgades kohtades, jõekaldal |
| Liivateed | Laste mänguala, kooliõu |
| „Jalatsitega tee" + „paljajalu tee" kõrvuti | Korea mudel — mõlemad variandid samas piirkonnas |

### D. Individuaalne üleminek (asfaldil elades)

Kui linnas pole veel muruväljakut:

| Samm | Tegevus |
|------|---------|
| 1 | Alusta **murul** — park, Pühali, koduõu; 5 minutit |
| 2 | Uuri **jalanõude** mõju (Lisa AA §10) |
| 3 | Kõva pinnal: **minimaalne jalats** või paljajalu lühikesi lõike — järk-järgult |
| 4 | Lühem samm, pehmem maandumine — mitte pikk samm asfaldil kohe |
| 5 | Küsi omavalitsuselt: **kus on meie muruväljak?** (Lisa L) |

### E. Omavalitsuse checklist (Lisa L)

- [ ] Kas igas linnaosas on **muruväljak või paljajalu ala** 5 min kaugusel?
- [ ] Kas kooliõuedel on **pehme pind** (mitte ainult asfalt)?
- [ ] Kas on **jalapesu** ja kingariiul avalikus paljajalu alas?
- [ ] Kas planeeringus on **„keha infrastruktuur"** — mitte ainult autod ja kõnniteed?

## 3. Rippumine — 90 sekundit päevas

### Miks rippumine?

Inimene on **ahv** — meie eellased rippusid ja ronisid. Tänapäeva linn eemaldas rippumise igapäevaelust. Tulemus:

| Ilma rippumiseta | Rippumisega |
|------------------|-------------|
| Õlad kinni, käed üleval ebamugav | Õla-liikuvus, haare |
| Selg „laptopi kumer" | Selja dekompressioon **aktiivse** rippumise kaudu |
| Haare nõrgeneb (vanus) | Haare tugevus — **pikaealisuse** indikaator (uuringud) |

**Vanja Moves** (Moves Method, schoolofmobility.com) õpetab: rippumine ei ole „venitamine pärast trenni" — see on **põhiliikumine**, mida tuleb **teenida** järk-järgulise koormusega.

### 90 sekundit päevas — miinimum

Renee positsioon operatsioonis:

> *Iga inimene peab saama rippuda **vähemalt 90 sekundit päevas** — mitte korraga alguses, vaid **kogumis** (nt 3×30 sek või 6×15 sek).*

**Vanja Moves** progressioon (Women's Health / Vanja intervjuu; schoolofmobility.com — Mobility & Injury Prevention Training):

| Tase | Kuidas |
|------|--------|
| **Algaja** | Tooli või jala abiga — **5–10 sek** kordi; eesmärk: keha harjub |
| **Kesktase** | Täis **dead hang** 20–40 sek; ehitada **90 sek** igapäevase koguni |
| **Edasijõudnu** | Eesmärk kuni **5 min** päevas; variatsioonid (käepidemed, skapula) |

**Oluline:** rippumine peab olema **aktiivne** — õlad kaasatud, mitte ainult „ripun ja lase käed välja".

**Kursus:** [schoolofmobility.com](https://schoolofmobility.com) — **Vanja Moves Mobility & Injury Prevention Training** (200 000+ õpilast; Moves Method).

### Igapäevane praktika kodus

| Tööriist | Märkus |
|----------|--------|
| Ukseraamile kinnitatav **tõmbekang** | Odav, kiire |
| **Lastetoa võrk** või rippumisribad | Pere ühine |
| **Kõrge lint** puus | Väljas, aias |
| Taimer telefonis | **90 sek** kogumis — mitte „kunagi meelde tuleb" |

## 4. Rippumisvõimalused linnaruumis — suurendada ja lisada

### Mida linnas praegu tihti on (ja mida pole)

| On | Puudub või vähe |
|----|-----------------|
| Laste mänguväljakud (madalad) | **Täiskasvanutele** kõrgemad ribad |
| Üksik välijõusaal | **Iga linnaosa** — mitte ainult kesklinn |
| Spordisaal (tasuline) | **Tasuta** õues, 24/7 ligipääs |
| Kontori tool | **Rippumiskohad** töö- ja koolitee ääres |

### Ettepanekud planeerijatele (Lisa L, Lisa J)

| # | Infrastruktuur | Detail |
|---|----------------|--------|
| 1 | **Kõrged rippumisribad** (monkey bars) | Min kõrgus täiskasvanule; mitu paralleelset riba |
| 2 | **Tõmbekangid** välijõusaalides | Standardne kõrgus, mitte ainult lastele |
| 3 | **Pargi „rippumissõlm"** | 2–3 kang + pingid + muru all |
| 4 | **Kooliõued** avatud õhtul | Rippumine peredele — mitte lukus pärast kella 16 |
| 5 | **Jõusaali asemel õues** | Odavam omavalitsusele; rohkem kasutajaid |
| 6 | **Märgistus** | „Rippumisala — eesmärk 90 sek päevas" (teadlikkus) |
| 7 | **Muruväljak + rippumisribad** ühes kohas | Keha täisvõimekus: jalad maas, käed õhus |
