## 1. Mida sa hingad — õhk korteris

### Miks see loeb otsuste jaoks

| Halb õhk | Mõju |
|----------|------|
| Liiga **kuiv** õhk (talvel küttega) | Käredad limaskestad, halvem uni, väsimus, peavalu |
| Liiga **niiske** õhk | Hallitus, allergiad, halb lõhn |
| **CO₂** koguneb (aknad kinni) | Uimasus, halvem keskendumine, lühemad otsused |
| **Tolm** ja filtrid täis | Hingamisteed, uni |

**Sa ei tee häid otsuseid uimas, kuivas või mürgises õhus.** Lisa V — uni enne silti. Lisa AB — keha vajab ka **värske õhku** liikumisel.

### SOP — korteri õhk (Eesti)

| Samm | Tegevus | Siht |
|------|---------|------|
| **1. Mõõda** | Osta **hügromeeter** (niiskus) — 10–25 €. Soovituslik ka **CO₂ mõõtja** (kallim, aga selge). | Tea, mis toimub |
| **2. Niiskus** | Suvel Eestis sageli OK. **Talvel** küttega korter: sageli **alla 30%** — liiga kuiv. | **40–60%** suhteline niiskus (üldine eluruumi siht) |
| **3. Kui liiga kuiv** | Niisuti (ultraheli), toalilled, pesu kuivatamine ruumis, avatud uks vannitoa järel duši järel. | Tõsta niiskust järk-järgult |
| **4. Kui liiga niiske** | Ventileeri, ära kuivata pesu magamistoas, kontrolli vannitoa ventilatsiooni, vajadusel niiskuse eemaldaja. | Alla 60%, hallitust ei tohi tekkida |
| **5. Ventileerimine** | **10–15 min** akna avamine 1–2× päevas (isegi talvel — lühike šokk). Või soojustagastusega ventilatsioon (KÜ). | Värske õhk, CO₂ alla |
| **6. Filter** | Vaheta **õhukonditsioneeri / ventilatsiooni** filtreid vastavalt juhendile. | Ei puhu sisse mustust |
| **7. Uni** | Magamistuba jahedam ja **puhas õhk** — mitte kümne inimese CO₂. Lisa V. | Uni = otsused homme |

**Küsimus endale:** *Millal ma viimati mõõtsin korteri niiskust — või otsustasin „nii on normaalne"?*

### Kiire checklist (kleep seinale)

```
[ ] Hügromeeter näitab 40–60% (või tean, miks mitte)
[ ] Täna ventileerisin 10+ min
[ ] Filter vaadatud (kui on)
[ ] Magamistoas ei kuiva pesu ega köögiviljad
[ ] Hallitust ei ole — kui on, ei maga seal
```

## 3. Miks rääkida võõrastega — komplimendid

### Kasu (teaduslik ja praktiline)

| Mida see teeb | Kellele |
|---------------|---------|
| **Tõstab tuju** mõneks tunniks | Sõnale saajale |
| **Aktiveerib sotsiaalset aju** | Sulle — vähem üksildust |
| **Õpetab tähelepanelikkust** | Sa hakkad **nägema** inimesi, mitte ekraani |
| **Ehitab ühiskonda** | Väike usaldus — ilma poliitikata |
| **Ei nõua vastust** | Üks lause, naeratus, edasi |

**See ei ole flirt.** See on **inimlikkus** avalikus ruumis — nagu vanasti külas, kus kõik teadsid üksteist.

### Komplimendi meetod — SOP (üks lause)

| Reegel | Selgitus |
|--------|----------|
| **1. Konkreetne** | Mitte „sa oled ilus" — vaid *mida sa täpselt märkasid* |
| **2. Mitte-seksuaalne** | Riietus, käimine, hoolivus, energia — **mitte keha, mitte „sexy"* |
| **3. Üks lause** | „Ma tõesti…" — ja **lõpp**. Ära seleta, ära jää kinni. |
| **4. Aus** | Ära ütle, mida sa ei mõtle. Parem vaikus kui vale. |
| **5. Avalik kontekst** | Tänav, pood, lift — mitte ööklubi või üksildane park öösel |
| **6. Ei oota tasu** | Ei numbrit, ei vestlust, ei „jätkame". Naeratus piisab. |
| **7. Valideeri tagasi** | Kui keegi ütleb „aitäh" — *„Palun."* ja edasi (Lisa P) |

**Vale kompliment** tundub nagu müük. **Õige kompliment** tundub nagu *„ma nägin sind ühe sekundi inimesena"*.
