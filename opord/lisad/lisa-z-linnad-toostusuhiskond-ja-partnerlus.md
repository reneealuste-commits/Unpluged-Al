## 1. Linn, mida me ise ehitasime

### Suletud toad

| Mida me ehitasime | Mida see teeb inimesele |

## 2. Rockefelleri ajastu ja tööstusühiskond — mis muutus?

**Ajalooline narratiiv** (uurimustöö, mitte üks tõde):

| Ajastu | Mudel |
|--------|-------|
| **Enne tööstusrevolutsiooni** | Pere/küla/talundus — töö ja elu **samal maal** |
| **19.–20. sajand** | Tehased, linnad, standardiseeritud haridus |
| **Rockefelleri / Carnegie ajastu** | Suur tööstus, fondid, haridussüsteemi standardiseerimine (uuritud ja vaidlustatud) |
| **Tänapäev** | Kontor, kaugtöö, gig-töö — **sama eraldatus**, uued vormid |

**Mida tööstusmudel eeldab:**

```
Isa → tööle (8–10 h) → raha → pere
Ema → kodus / tööl / mõlemad → lapsed koolis/lasteaias
Lapsed → standardne haridus → töötajad homme
```

**Probleem:** isa **ei ole kohal**. Emal on **ülekoormus**. Lapsel puudub **eeskuju** päevas (Lisa H, Lisa S). Pere on **õnnetu** — mitte sellepärast, et inimesed on halvad, vaid struktuur on vale.

> *Kriitiline mõtlemine:* Rockefelleri süüdistamine üksi on liiga lihtne. Aga **töö ja pere eraldatus** on dokumenteeritud tööstusühiskonna tunnus — ja see kehtib täna endiselt.

## 3. „Orav rattas" — raha eemale, pere eemale

| Samm | Mis juhtub |
|------|------------|
| 1 | Isa (või ema) läheb linna tööle |
| 2 | Raha tuleb — üür, toit, kool |
| 3 | Aeg perega **väheneb** |
| 4 | Lapsed otsivad tähelepanu mujalt (ekraan, kanalid) |
| 5 | Pere lõheneb või jääb **tühjaks** |
| 6 | Uuesti tööle — et maksta lahendamata probleemide eest |

**Starfish Academy** (operatsioonis) aitab inimestel **väljuda orav rattast** — finantsvabadus, mitte ainult palgatöö. **BNI** ühendab ettevõtjaid, kes **soovitavad** üksteist — mitte anonüümne korporatsioon.

**Seos Lisa Y-ga:** kui surve on struktuurne (eraldatus), otsib inimene **rahustit** — alkohol, tablett, ekraan, illegaalne kanal. Juur on **mudel**, mitte ainult iseloom.

## 4. Tagasipöördumine partnerluse ja ettevõtluse juurde

> *„Everybody must now return back to entrepreneurship / partnership"* — mitte kõik peavad olema startup-id. **Partnerlus** tähendab: pere, küla, ettevõte **ühes laevas**.

### Mida „partnerlus" tähendab praktikas

| Vanamudel | Uus suund (võimalik Eestis) |
|-----------|----------------------------|
| Isa kontoris 9–17 | Pereettevõte, kaugtöö, küla-talund |
| Lapsed lasteaias 8 h | Lühem päev, laiendatud pere, Montessori (Lisa W, J) |
| Töö „mujal", elu „kodus" | Töö **kodus** või **külas** — Pühali mudel |
| Raha ainult palgast | Ettevõtlus, BNI, Starfish, põllumajandus, käsitöö |
| Linnastumine lõputu | **Maapiirkonna** elujõud — omavalitsused, riik |

### Näited operatsioonis

| Näide | Mida see näitab |
|-------|-----------------|
| **Urmas Sõõrumaa / Pühali** (puhali.ee) | Küla taastamine — töö, puhkus, pere **samal maal** |
| **BNI Tallinn** | Ettevõtjad, kes **usaldavad** üksteist — mitte korporatsioon |
| **Starfish Academy** | Finantsvabadus — väljumine palgatöö orav rattast |
| **Montessori / Waldorf** (Lisa J) | Laps **kohal** — mitte ainult konveier |
| **Lisa E — pere rindejoon** | Isa **kohal** — mitte ainult palganumber |

### „Oma laev" (on your own ship)

```
Pere + töö + elukoht + kogukond = üks süsteem
Mitte: isa laev = töö, pere laev = kodu (kaks eraldi laeva)
```

**Eesmärk:** isa (ja ema) **nähtav** lastele; raha **ei nõua** pere lagunemist; õnn **ei ole** luksus — see on struktuuri küsimus.

## 5. Alustada Eestist — seestpoolt valitsust

Operatsioon ei ütle „põgene riigist". Operatsioon ütleb: **muuda riiki seestpoolt** — aus tagasiside, perede KPI-d, poliitika.

### Lisa L — Muski 5-astmeline algoritm ministeeriumidele

| Samm | Pere-partnerluse suunis |
|------|-------------------------|
| Küsi „miks?" | Miks poliitika eraldab töö ja pere? |
| Eemalda sammud | Bürokraatia, mis sunnib mõlemad vanemad täiskoormusele |
| Lihtsusta | Üks kontakt punkt perele — mitte 7 ametit |
| Automatiseeri | e-Eesti — vähem aega kontorites |
| Kiirenda | Otsused, mis toetavad **kodu lähedal tööd** |

### Konkreetsed poliitika-suunad (ettepanekud, mitte käsk)

| Valdkond | Ettepanek |
|----------|-----------|
| **Maksundus** | Pereettevõtte soodustus; kodukontori maksuvabastus |
| **Haridus** | Lühem koolipäev; Montessori/Waldorf kättesaadavus (Lisa J) |
| **Maapiriirkond** | Internet, transport, eluaseme — et **ei pea** Tallinna pendeldama |
| **Perepoliitika** | Isa kohalolek — mitte ainult „emadepäev" |
| **Ettevõtlus** | EAS, BNI, käsitöö, põllumajandus — **kodu lähedal** |
| **Lisa T tagasiside** | Ministrid peavad kuulma perede KPI-sid — mitte ainult SKP-d |

### Omavalitsused — esimene front

Eesti on väike. **Küla, vald, linn** saavad teha rohkem kui oodata:

- Kohalik ettevõtlus (pood, käsitöö, turism)
- Pereklubid, isa-grupid (Lisa H)
- Kooli koostöö vanematega (Lisa J, N)
- Pühali-tüüpi keskused — **töö + pere + loodus**
- **Muru väljakud** igas linnaosas — paljajalu alad, pehme pind (Lisa AA §10; Hi on Life festival Pühalis kui prototüüp)

**Jalanõud ja asfalt:** linn planeerib auto ja kõva pinna jaoks. Keha vajab **murdu** — eriti laste jalad. Uurimustöö jalanõude mõju kohta: Lisa AA. **Paljajalu kõndimine murul** peab tagasi tulema — mitte ainult üksik festival Pühalis.

> *Alustada saab Eestist — sest me oleme väikesed, paindlikud ja digitaalsed. Aga ainult kui **valitsus kuuleb** — Lisa T, Lisa P, Lisa X (tagasiside).*

## 6. CASE STUDY'D — mudel vs partnerlus

| | |

| **Tulemus** | Laps 12-aastaselt ekraanisõltuv; pere „koos" ainult nädalavahetusel |

### Case 2 — „Liina": üksikema orav rattas

| | |
|--|--|
| **Mudel** | Töö + lapsed + üür; isa puudub |
| **Tulemus** | Burnout; laps koolikiusamise ohver (Lisa S) |
| **Pööre** | Laiendatud pere (vanaema); Starfish finantskoolitus; kogukonna tugi |
| **Õppetund** | Partnerlus ei ole ainult abielu — **kogukond** on laev |

### Case 3 — Pühali: küla kui partnerlus

| | |
|--|--|
| **Mudel** | Urmas Sõõrumaa — töö, puhkus, pere, küla **ühes kohas** |
| **Tulemus** | Elujõud tagasi maapiirkonda; inimesed **ei pendelda** |
| **Õppetund** | Ettevõtlus + maapiirkond = võimalik Eestis |

### Case 4 — BNI: ettevõtlus ilma korporatsioonita

| | |
|--|--|
| **Mudel** | Üks ettevõtja kutseala; soovitused teistelt |
| **Tulemus** | Stabiilsem sissetulek; **kontroll oma ajal** |
| **Õppetund** | Raha võib tulla **partnerlusest**, mitte ainult palgast |

### Case 5 — Valitsus kuulab (või ei kuula)

| | |
|--|--|
| **Lisa T** | Sündide langus, usaldus 30% — tulemused räägivad |
| **Küsimus** | Kas minister muudab poliitikat, kui perede KPI halveneb? |
