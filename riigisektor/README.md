| [techno-tln-austus-sisekorra-eeskiri.docx](techno-tln-austus-sisekorra-eeskiri.docx) | Kolledi sisekorra eeskiri — väärtused, rollid, konflikt, turvalisus |

## Taasgenereerimine

```bash
python3 riigisektor/scripts/generate_austus_juhendid_docx.py
python3 riigisektor/scripts/generate_seinale_poster.py
```

## Põhimõte

Reeglid on vajalikud, et oleks **selgus** ja **turvalisus**. Austus ei ole pehme lisaväärtus — see on töökorraldus.
